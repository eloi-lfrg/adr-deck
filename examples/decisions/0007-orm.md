# ORM pour le service de commandes

## Context and Problem Statement

Le service de commandes écrit ses requêtes SQL à la main, sans typage.

## Considered Options

* TypeORM
* Requêtes SQL brutes

## Decision Outcome

Superseded by ADR-0008, because TypeORM ne suit plus nos besoins de typage.

## Pros and Cons of the Options

### TypeORM

* Good, because décorateurs familiers à l'équipe

### Requêtes SQL brutes

* Bad, because aucun typage
